Uusia projektisivuja voi luoda _posts kansioon:
1. Luo kansioon uusi tiedosto jonka nimi on vv-kk-pv-projektin-nimi.markdown
2. Lisää tiedoston alkuun tarvittavat metatiedot (näkyvät etusivulla) tässä muuodossa:
      ---
      layout: post
      title: "MALENAN POLKU I&II"
      start_date: Kampissa 29.06.2014 (Tässä voi olla myös pelkkä pvm)
      end_date: 27.06.2015
      categories: jekyll update
      ---
3. Kirjoita projekti-sivun sisältö Markdownilla. https://www.markdownguide.org/cheat-sheet/
